# Thinking Tools

## Purpose

E001–E234の各教材で使う「考え方」を、個別Eの中だけで終わらせず、**問題を見たときに何を考えるかの共通ツール集**として横断整理する。

これは新しい問題バンクではない。既存Eで実際に導入・使用した思考操作を再利用しやすくするための索引である。

## Learner-facing role

共通ページ名は **思考ツール**。

導入文は:

> 問題を見たとき、何を考えればいいか迷ったらここを見る

とする。

各ツールは「用語の定義」より、解く側が自分に投げる**問い**として示す。

例:
- 目的: この問題では、何を達成したいのか
- 外せない条件: 結論を出すとき、必ず満たすべき条件は何か
- トレードオフ: この案で得るものと、弱くなるものは何か
- 最後の判断: 最終的に何を選ぶ・勧める・説明する問題なのか

## Accumulation rule

思考ツールは最初から完成した巨大分類を与えない。

1. 個別Eで実際に考え方を使う
2. REVIEWでその考え方を明示する
3. 別題材でも使える問いへ圧縮する
4. 思考ツールページへ追加する

この順を守る。

したがって、**derivation before taxonomy** を維持する。共通ページは分類を先に暗記させる場所ではなく、教材で得た思考操作を整理して再利用する場所である。

## Lesson cue

各EのSTARTには、その回で使う思考ツールだけを短く提示してよい。

ルール:
- 原則2〜4個程度
- 全ツールを毎回表示しない
- learner-facing labelは短くする
- 必要なら英語ラベルを補助表示する
- 共通ページの該当ツールへリンクする
- 問題の答えそのものを先出ししない
- canonicalのStrategy / explanationに根拠があるものだけ選ぶ

## Current seed set

代表教材からまず以下を収録する。

- E001: 残る失敗 / 必要条件
- E049: 文中の役割 / 周囲の手掛かり / 論理に合うか
- E097: 目的 / 外せない条件 / トレードオフ / 最後の判断
- E145: 定義 / 構成要素 / 近い概念と分ける / 限界

加えて、E097・E145の解説から、判断基準・同じ軸で比較・確かめられるか・射程なども共通ページへ整理する。

## Content ownership

- canonical lesson content: `bundles/Bxxx/Exxx.md`
- cross-lesson thinking-tool index: `site/src/data/thinking-tools.js`
- learner-facing page: `/thinking-tools/`

viewer独自の答えや新しい論点を大量に作らない。ツール追加は必ず既存教材のStrategy / explanation / 次へのポイントに遡れること。

## Expansion

E193 / E205の代表実装時にも新しい思考操作があれば同じ手順で追加する。

全E002–E234へ一般化する段階では、各教材のSTARTにどのツールを出すかをauthoring metadataまたはcanonical contentから導出できる形へ移行し、234ページへ手作業で独立した一覧を持たせない。
