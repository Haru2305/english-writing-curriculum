# P2 Accelerated Route — 2026-10 onward

## Purpose

P2の全54教材を順番に必修化しない。

2026年10月以降の標準運用では、P2は **30回のCore Route** に圧縮する。残り24教材は削除せず、Checkpointで弱点が出た場合にだけ戻る Targeted Review として使う。

P2はP1より新規技能が多いため、P1ほど大胆には削らない。構文処理・段落・複数本文・資料統合・推論・要約・60→80→90語Writingの階段を残し、同じ技能のTransfer反復を主にOptionalへ回す。

## Operating rule

1. Core Routeを順番に進める
2. 各Checkpointを解く
3. Checkpointで明確な弱点が出た技能だけ、同BundleのOptionalへ戻る
4. Optionalを全部消化しない
5. E096終了後はP3へ進む

## Time implication

- Full P2: 54 lessons
- Accelerated P2: 30 lessons
- Removed from default route: 24 lessons
- Default P2 volume reduction: about 44%

P1 15回＋P2 30回なら、標準ルートでは45回でP3入口E097へ到達する。
