# Phase Design

## P1 — 基礎補強・概念形成

目的:
- 文構造・文法・表現・論理の概念像を作る
- 正確性を優先する
- 日本語支援を十分に使う

## P2 — 処理速度・論理

目的:
- 段落機能、推論、要約、複数資料処理を強化
- 既習表現を未知題材で再利用
- 時間意識を上げる

## P3 — 入試実戦化

目的:
- 特定大学に過学習せず、複数形式へ対応できる汎用入試力を完成
- 語彙・構文・抽象度・情報密度・推論・出力切替を統合
- 終盤は「1教材 ≒ 60分模試型」へ寄せる

Current:
- B022–B034 / E127–E204 completed
- P3 completed at B034 / E204. Next: P4 Tsukuba
- planned end = E204前後
- B034 = P3 Final Gate

P3では原則として major new Focus を増やさず、既習技能の Transfer / Checkpoint を中心にする。

期間:

- B035–B039
