# Self-assessment Framework

## Purpose

This framework aligns self-check, revision, and feedback with the argument-construction system used across E001–E234.

It is a **learner diagnostic framework**, not an official university scoring rubric.

The central rule is:

> Do not polish sentences before checking whether the answer actually answers the question and forms a traceable argument.

No new lesson IDs are created.

---

# 1. Two different questions

A free-writing answer must be checked on two different levels.

## Answer-level quality

- Did I answer the prompt?
- Is the argument traceable?
- Is the reason developed rather than listed?
- Does the example support the reason?
- Is the claim appropriately qualified?

This is primarily:
- WQ00 Task fulfillment
- WQ04 Effective
- ARG01–ARG06
- WF-specific argument route

## Sentence-level acceptability

- Is the sentence understandable?
- Is the grammar safe?
- Is the wording precise?
- Is the expression natural?

This is primarily:
- WQ01 Correct
- WQ03 Precise
- WQ02 Natural
- AC01–AC05

A grammatically acceptable answer can still be a weak answer if the argument is missing.

---

# 2. Self-check order

For timed free writing, use this order.

## SA00 — Task Gate

**Question:** Did I answer exactly what was asked?

Check:
- direct answer / position
- every required condition
- source conditions where relevant
- requested example / comparison / recommendation
- word-count or format constraints when they are part of the task

Related:
- WQ00
- ARG01

If this fails, fix it before anything else.

---

## SA01 — Argument Integrity

**Question:** Can the reader follow why my answer should be accepted?

Check the functions needed by the WF type.

Typical route:
- Answer
- Reason
- Mechanism
- Support
- Qualification if useful
- Return / Decision

Do **not** require all ARG01–ARG06 in every answer.

Examples:
- WF01 often needs Answer → Reason → Mechanism → Support → Return
- WF03 centers on Mechanism
- WF04 needs Proposal → Mechanism → Limitation/Mitigation
- WF05 needs Criteria → Evaluation → Choice

Related:
- WQ04
- ARG01–ARG06
- WF01–WF07

High-impact failures:
- reason is just another opinion
- mechanism is missing
- example does not support the reason
- comparison uses different criteria
- concession is added but never resolved
- answer ends without returning to the judgment

---

## SA02 — Meaning & Correctness

**Question:** Is any sentence hard to interpret because grammar or meaning relations break down?

Prioritize:
- subject–verb relation
- tense / number where meaning changes
- complement / preposition errors that change meaning
- missing or ambiguous reference
- sentence structure that obscures the claim

Related:
- WQ01
- AC01

Do not spend the last minute fixing tiny style issues while one sentence is still difficult to understand.

---

## SA03 — Precision

**Question:** Am I saying exactly as much as the evidence and argument justify?

Check:
- always / never / all / only
- may / can / tend to / suggest
- subgroup vs everyone
- association vs causation
- proxy vs outcome
- pronoun / noun reference
- scope of a condition or exception

Related:
- WQ03
- ARG05
- TH07 / TH08 where relevant

Precision is checked before surface naturalness in timed revision because an overclaim can damage the argument.

---

## SA04 — Naturalness

**Question:** Is there an awkward expression that can be replaced safely and quickly?

Check:
- unnatural subject choice
- direct translation from Japanese
- collocation
- unnecessary repetition
- needlessly complex wording

Related:
- WQ02
- AC03–AC05

Do not rewrite a clear sentence merely to make it sound sophisticated.

---

# 3. Revision priority

Under time pressure, fix the **highest-impact problem**, not the easiest visible problem.

Priority:

1. Task miss / missing required element
2. Broken argument link
3. Meaning-breaking grammar
4. Overclaim / imprecise scope
5. Awkward but understandable language
6. Cosmetic style

Compressed cue:

> **問い → 論理 → 意味 → 範囲 → 自然さ**

This is the revision order.

It is different from the long-term learning progression, where learners may study Correct → Natural → Precise → Effective as separate skills.

---

# 4. Diagnostic outcome

Use A / B / C only as a **learning diagnosis**, not as a predicted admissions score.

## A — Ready

- Task is fulfilled
- required argument route is traceable
- no meaning-breaking error
- claim strength is broadly appropriate

Minor awkwardness is acceptable.

## B — Repairable

- Task is basically fulfilled
- answer is understandable
- but one high-impact weakness remains

Examples:
- mechanism is thin
- support is vague
- trade-off is not resolved
- one recurring grammar problem
- claim is slightly too strong

The learner should identify **one primary repair target**.

## C — Rebuild

Any of:
- prompt not directly answered
- required element missing
- argument cannot be followed
- major sentence meaning is unstable
- answer is incomplete

The first repair should target structure or meaning, not style.

---

# 5. Relationship to AC01–AC05

AC is not a whole-answer grade.

| AC | Meaning | Whole-answer implication |
|---|---|---|
| AC01 | sentence meaning unstable | usually SA02 failure; may cause C |
| AC02 | grammatical but Task / meaning mismatch | SA00 failure; often C |
| AC03 | acceptable but weak / unnatural | usually SA04 issue; often still B or A |
| AC04 | natural and appropriate | sentence is usable; argument still must be checked |
| AC05 | different but equally valid wording | confirms model-answer matching is unnecessary |

A response made entirely of AC04 sentences can still be weak if ARG02–ARG03 are missing.

---

# 6. Model-answer policy

The model answer is a **worked example**, not a wording key.

When comparing with a model answer, compare:

1. Task fulfillment
2. argument functions
3. scope / qualification
4. language choices

Do not compare:
- exact vocabulary
- exact sentence order unless the logic requires it
- identical examples
- identical conclusion wording

The learner should be able to say:

> My wording is different, but my answer performs the same necessary functions.

---

# 7. Phase progression

## P1

Keep self-check light.

Primary checks:
- answered the short task
- meaning is clear
- target language can be used safely

Do not retrofit a full SA00–SA04 checklist into every P1 lesson.

## P2

Introduce answer-level checking explicitly.

Best point:
- when WP01 Plan→Draft→Revise becomes visible

Learner begins to separate:
- argument problem
- language problem

## P3

Self-assessment becomes diagnostic.

Learner should identify:
- missing mechanism
- weak evidence
- overclaim
- unresolved concession
- imprecise criterion

before surface wording.

## P4

Compress to a fast exam routine.

### Before writing
> 答えは？ → なぜ？ → どうして？ → 具体的には？ → 例外は？ → だから？

### Final check
> 問い → 論理 → 意味 → 範囲 → 自然さ

The final check must fit the available review window.

---

# 8. WR01 / WR02 alignment

## WR01 Self-check

Current curriculum intent should be read as:

> Task → Argument → Meaning/Correctness → Precision → Naturalness

not:

> grammar → naturalness → precision → logic

The latter encourages polishing before fixing a missing argument link.

## WR02 Revision ladder

WR02 remains useful for deliberate practice, but two modes must be distinguished.

### Learning-mode ladder

> Correct → Natural → Precise → Effective

Useful when comparing alternative rewrites without strict time pressure.

### Exam-mode repair order

> Task → Argument → Correct → Precise → Natural

Useful when only one or two revisions are possible.

# 9. Curriculum audit finding

Representative lessons already support this framework:

- E087 checks whether every sentence has an argument role
- E093 checks criteria consistency and trade-off
- E117 checks every causal arrow
- E119 checks source integration and qualified language
- E208 checks direct answer, one focused reason, and supporting example

Therefore the main gap is **not missing self-check content**.

The gap is:
1. no curriculum-wide self-assessment order,
2. WR01 management wording places logic too late,
3. P1 metadata under-tags WQ00 despite the stated “all writing” rule,
4. AC categories can be misread as whole-answer grades unless explicitly separated.
