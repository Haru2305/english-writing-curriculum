# Learner-facing Core Concepts

## Purpose

E001–E234の全てのIdeaを学習者に明示するのではなく、**反復実績がある27個**を Learner-facing Core とする。

選定条件:
- Canonical Idea Bankに存在する
- 既存E001–E234の中で2教材以上に明示リンクされている
- 新規教材を追加しない

残りのIdeaは、Supporting / Bank-onlyとして保持する。教材に現れたからといって、必ず名称を暗記させる必要はない。

## Three-stage rule

### Introduce

初出教材のPost-solveで:
- Ideaの短い名前
- 1文定義
- その教材での具体形

を示す。

目的は「概念に名前を与える」こと。

### Recall

再登場教材では完全解説を繰り返さない。

- 「前に扱った○○と同じ構造」
- 10〜20秒で思い出す問い

程度に留める。

目的は retrieval。

### Transfer

別題材への転用では、原則として**解答前にIdea名を提示しない**。

解後のPost-solveで:
- 「実はこれはE___の○○と同じ」
- 元題材と新題材の対応
- もう1題材への転用問い

を示す。

目的は cue-dependent recall ではなく spontaneous transfer。

## Visibility rule

- 1教材に learner-facing Core を大量表示しない
- Primaryは原則1個、必要ならSecondary 1個まで
- 読解技術や文法の主目的を邪魔する場合はPost-solveだけに置く
- Checkpointでは新しい名称を導入しない
- P4では試験運用を崩さず、Post-solve 1〜2分の範囲で再会だけを示す
- 「似ている」だけでTransferを捏造しない。適切な既存教材がなければPartialのまま保持する

## Revision priority

### Priority A — explicit naming is especially valuable

- IDEA0058 self-selection bias
- IDEA0062 proxy ≠ outcome
- IDEA0063 association / confounding / causation
- IDEA0064 average ≠ distribution
- IDEA0065 visible evidence is selected evidence
- IDEA0066 feedback loop
- IDEA0057 evidence strength → claim strength
- IDEA0028 efficiency ≠ resilience
- IDEA0010 equal treatment ≠ equal opportunity
- IDEA0050 known / unknown / action

These concepts are highly transferable and recur in later exam-like materials.

### Priority B — useful argument-building concepts

- IDEA0001 structural causes
- IDEA0003 supplement rather than replace
- IDEA0018 human oversight in high-risk use
- IDEA0020 privacy vs utility
- IDEA0026 upfront cost vs long-term benefit
- IDEA0035 task-level change
- IDEA0041 opportunity cost
- IDEA0042 participation / accountability / trust
- IDEA0043 preserve vs adapt
- IDEA0049 invisible prevention benefit
- IDEA0054 public benefit vs alternative use
- IDEA0055 benefit-risk frame

### Priority C — keep explicit but do not force extra transfer

- IDEA0031 fixed-cost service maintenance
- IDEA0037 cross-border cooperation
- IDEA0056 meaningful consent
