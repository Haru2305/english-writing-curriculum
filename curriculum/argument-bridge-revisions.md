# Selected Argument-Bridge Revisions

Scope: four existing materials only. No new lesson IDs.

The purpose is not to teach another template. It is to make the existing local structures recognizable as one transferable argument-construction system.

## E087 — ARG01-ARG06 / Introduce

論証の共通回路｜ARG01–ARG06

これまでのclaim / reason / limitation / actionは別々の型ではなく、同じ論証生成の一部として考える。問いに答える→理由→なぜ成り立つか→具体化→必要なら限定→問いへ戻る。すべてを毎回使う必要はない

自分への問い｜「この段落で、理由から結論までの間に欠けている役割は何か」

## E117 — ARG03 / Recall

論証再会｜ARG03 Mechanism

E087で整理した共通回路の「どうして？」に当たる部分。原因と結果の間のmechanismを一段ずつ書けば、becauseやthereforeだけで因果を飛ばしにくい

自分への問い｜「この結果の直前に、何が変化したのか」

## E119 — ARG05 / Recall

論証再会｜ARG05 Qualification

E087の共通回路でいう「例外は？」の部分。譲歩は立場を弱めるためではなく、claimの適用範囲を正確にしてから中心判断へ戻るために使う

自分への問い｜「何を認めても、最終的に何を主張し続けるのか」

## E208 — ARG01-ARG06 / Transfer

本番用に圧縮｜6つの問い

教材で使った論証機能を本番ではラベルで考えない。60〜90秒で「答えは？→なぜ？→どうして？→具体的には？→例外は？→だから？」を走査し、必要なものだけ選ぶ

自分への問い｜「理由を増やすより、1つの理由を最後まで発展させられているか」


Selection logic:
- E087 names the common system once when explicit planning begins.
- E117 reconnects causal writing to ARG03 Mechanism.
- E119 reconnects concession to ARG05 Qualification.
- E208 compresses the system into exam-time internal questions.

P1 remains unchanged.
