E110｜機械翻訳の注意書き：どこまで強く言うべきか

P3 / LT02 / A12 語用・レジスター / A10 / TF16



今日の狙い

文法的に正しい表現の中から、証拠の強さ・読み手・用途に合う断定度を選ぶ。may / can / is likely to / does not guarantee などを、弱くするためではなく意味を正確にするために使う。



時間配分

Register Guide 6分 / Reading 16分 / Questions 10分 / Writing Task 15分 / Revision 6分 / Self-check 3分 / Post-solve 4分 ＝ Core 60分



Register Guide

強さを調整する4点

1. evidence strength

2. scope

3. audience

4. consequence of error

学術文・注意書きでは、過剰断定も過剰hedgingも不適切。



Reading

[1] Automatic translation tools can make information available quickly across languages, but their reliability varies with context. A system may perform well on familiar sentence patterns and still produce serious errors when a word has several meanings, when the source contains an omitted subject, or when specialized terminology is used.



[2] This variation matters because not every translation error has the same consequence. A slightly awkward phrase in a travel review may be inconvenient without changing the reader’s decision. An inaccurate instruction about medication, safety, or legal procedure can have much more serious effects.



[3] For high-consequence communication, it is therefore misleading to say either that automatic translation is “unreliable” in general or that it “works.” Both statements are too broad. The more useful question is what kind of text is being translated, how the output will be used, and whether a knowledgeable person can review uncertain passages.



[4] Human review is also not a guarantee of perfection. A reviewer may miss an error, misunderstand the original, or lack relevant specialist knowledge. Still, review can reduce certain risks by identifying ambiguous terms and checking whether important instructions have preserved their intended meaning.



[5] Good guidance should reflect these limits. It might say that automatic translation can support access to routine information but should not be treated as a substitute for qualified interpretation in situations where a translation error could materially affect health, safety, or rights. Such wording is cautious because the evidence is conditional, not because the writer lacks a position.



Questions

Q1｜RQ10

Why does the author reject both “automatic translation is unreliable” and “automatic translation works” as general statements?



Q2｜A12

Which sentence best matches the author’s register?

A. Automatic translation always fails in serious situations, so it should never be used for health or legal text.

B. Automatic translation is probably useless for important information, so it is better avoided altogether.

C. Automatic translation can support routine access, but high-consequence uses may need qualified review.

D. Automatic translation is basically accurate if a human checks it, so review removes the main risk.



Q3｜RQ09

What can reasonably be inferred about human review?



Writing Task

Rewrite the following notice in 80–100 English words so that its claim strength matches the passage:



“Automatic translation gives correct information quickly. You can use it for all public information, but you should check the result if you want.”



Your revision must:

- state one useful role

- identify one higher-risk context

- avoid absolute claims

- explain when review matters



Self-check

□ My modal verbs match the evidence.

□ My scope is no broader than the passage.

□ I avoided vague weak language.

□ The notice still gives a clear practical message.

解答・解説・自己修正



Reading answers

Q1｜解答例

Because reliability depends on text type, ambiguity, terminology, use, and consequence, so both blanket statements erase conditions that matter.



Q2｜C

It preserves the useful role while limiting the claim in high-consequence settings.



Q3｜解答例

Human review can reduce some risks but cannot guarantee a perfect translation, especially if the reviewer lacks relevant knowledge.



A12｜語用・レジスター

hedgingは弱腰ではない。

can / may / is likely to / does not guarantee

を使って、claimのscopeとcertaintyを証拠に合わせる。



Model answer

Automatic translation can provide quick access to routine public information, especially when the text is simple and the consequences of small errors are limited. However, it should not automatically be relied on for medical, safety, or legal instructions, where a mistranslation could have serious effects. In such cases, uncertain or important passages should be reviewed by someone with relevant language and subject knowledge. Human review can reduce risk, although it cannot guarantee that every error will be found. That review should focus on consequential ambiguity.



Self-correction

助動詞だけを増やして意味が曖昧になっていないか確認する。「何ができる／何は保証しない」が読み手に明確かを見る。

C：正誤だけを考え、claim strengthを調整しない。
