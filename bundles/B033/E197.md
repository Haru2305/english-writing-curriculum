Reading
[1] People often treat a preselected option as a neutral starting point, but default settings can influence behavior. If a form automatically selects one option unless the user changes it, some users will remain with that option even when alternatives are available.

[2] Several mechanisms can produce this effect. Changing the default requires attention and effort, however small. Some users may also interpret the default as a recommendation from the designer. Others may simply postpone the decision and never return to it.

[3] A default is not therefore equivalent to a command. Users can still choose differently. Its influence is better understood as changing the path of least resistance.

[4] This distinction matters when evaluating whether defaults are appropriate. A default may be useful when one option is safe for most users and switching is easy. It is more problematic when preferences differ greatly, the consequences are serious, or users may not notice that a choice has already been made for them.

[5] Designers should therefore judge defaults by both outcome and reversibility. A high rate of staying with the default does not by itself prove that the default matched users’ preferences.

Q1｜解答例
Switching requires effort and attention; users may interpret the default as a recommendation; or they may postpone the decision and never change it.

Q2｜解答例
Because users remain free to select another option; the default changes the easiest path rather than removing alternatives.

Q3｜解答例
Users may stay because switching takes effort, because they overlook the setting, or because they infer a recommendation, not because the option best matches their preference.

Q4｜解答例
Preselected option → user postpones active choice → no later reconsideration → default remains unchanged.

Model writing
Automatic enrollment in reminder messages is reasonable if the messages are low-risk, easy to stop, and clearly disclosed when equipment is borrowed. The passage suggests that defaults can help by reducing the effort required to choose a generally useful option, but staying with a default does not prove that users prefer it. The library should therefore provide a simple opt-out link and explain that enrollment is automatic. If many students report unwanted messages or reminders create important privacy concerns, the system should be revised rather than treating high enrollment as evidence of satisfaction. The policy should also state how complaints will be reviewed.
