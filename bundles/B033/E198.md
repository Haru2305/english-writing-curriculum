Passage
[1] A useful map is not a complete copy of the world. Every map selects, groups, and simplifies information so that particular patterns can be seen.

[2] This is especially clear in digital route maps. At a wide zoom level, minor streets may disappear, building outlines may be removed, and several categories of road may be merged. The goal is not to claim that these features do not exist but to prevent the display from becoming unreadable.

[3] Simplification, however, can create errors of interpretation when users forget that information has been filtered. A road omitted at one zoom level may still be physically present. A neighborhood boundary drawn as a sharp line may in reality be uncertain or socially contested.

Candidate Sentence
The same visual clarity that helps a user act quickly can therefore hide uncertainty or variation that matters for a different task.

[4] Map designers respond by using multiple layers and scales. A navigation layer may prioritize road connections and travel time, while a planning layer may show parcel boundaries, elevation, or uncertainty. Neither layer is simply “more accurate” in every sense; each is optimized for a different use.

Dense Sentence
Because selection is unavoidable, evaluating a map requires asking not whether it includes every available detail but whether the details it suppresses are irrelevant to the decision the map is being used to support.

[5] This shifts the question from completeness to fitness for purpose. A simplified map can be excellent for rapid navigation and poor for legal boundary analysis at the same time.

Design Note
At low zoom, Map X suppresses minor roads and uncertainty markers. At high zoom, those features become visible.

Table
Task | Best layer | Main reason | Main risk if wrong layer used
Fast driving route | Navigation | clear major connections | hidden local restrictions
Property boundary check | Parcel | detailed boundary data | oversimplified lines
Flood planning | Terrain | elevation and drainage | missing vertical information

Q1｜解答例
Paragraph 3 introduces the main risk of simplification: users may mistake filtered representation for complete reality.

Q2｜解答
After paragraph 3. “The same visual clarity” refers back to the simplification described earlier, and the sentence summarizes the trade-off before paragraph 4 presents the design response of using multiple layers.

Q3｜解答例
Every map must leave out some information. Therefore, we should not judge a map by whether it contains every possible detail. We should ask whether the omitted details matter for the decision the map is supposed to support.

Q4｜解答例
The note shows that visible information changes with scale, while the table shows that different tasks require different layers and that using the wrong layer creates task-specific risks.

Q5｜解答例
Because extra detail may be irrelevant or distracting for one task, while a simpler map may better support a quick decision; usefulness depends on purpose.

Model summary
Maps necessarily simplify reality by selecting which details to display. This can improve clarity, but users may misinterpret omitted roads, sharp boundaries, or missing uncertainty as if they did not exist. Digital maps therefore use different layers and scales for different tasks. The key principle is fitness for purpose: a map should be judged by whether the information it suppresses matters for the decision being made, not simply by how much detail it contains.

Model writing
A school should provide several task-specific campus maps rather than one simplified map for every purpose. A general navigation version could emphasize major paths and building names, making quick movement easier. Separate accessibility or emergency maps could show elevators, ramps, restricted areas, or evacuation routes that would clutter the basic version. The source set shows that simplification is useful only when omitted details are irrelevant to the task. The school should therefore keep the maps linked and clearly labeled so students know when a different layer is needed. That separation keeps each map usable.
