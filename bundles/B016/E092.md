E092｜公共施設のキャンセル対策：問題に合う提案を書く
P2 / LT03 / WF04 提案・解決策 / WQ04 Transfer / TF14
今日の狙い
D03で読んだproblem→solution対応を、自分の英作文へ移す。提案そのものより「なぜその問題に効くのか」「副作用をどう抑えるか」を90〜110語で示す。WQ04を別文脈Free answerとして回収する。
時間配分
Proposal Guide 5分 / Reading 14分 / Questions 7分 / Writing Task 20分 / Revision 8分 / Self-check 3分 / Post-solve 3分 ＝ Core 60分
Proposal Guide
problemを1文で定義してから書く。
Proposal:
Mechanism:
Limitation:
Mitigation:
の4点を揃える。
Reading
[1] A community center allows residents to reserve meeting rooms online without payment. The system is popular, but staff often find that a room remains empty even though the schedule shows it as fully booked. Some users make several reservations while planning an event and cancel only one of them at the last moment.
[2] The center could simply limit every person to one reservation, but that rule would also affect groups that genuinely need several dates for a course or project. Charging a large cancellation fee might reduce unnecessary bookings, yet it could discourage small volunteer groups whose plans are sometimes uncertain.
[3] A more targeted approach would be to require users to confirm each booking two days before use. Unconfirmed bookings would be released automatically, while groups needing several dates could keep them by confirming each one. The center could first test the rule for one month and record how many rooms are released and later rebooked.
[4] The value of the trial would depend on what problem it actually measures. If many unconfirmed rooms are quickly taken by other users, the rule is probably reducing blocked access. If rooms are released but remain empty, the deeper problem may be low demand rather than overbooking.
Questions
Q1｜D03
What problem is the confirmation rule designed to reduce?
Q2｜RQ09
If many released rooms remain empty, what can reasonably be inferred?
Writing Task
Write 90–110 English words answering:
“What should the community center do next?”
Your answer must:
- define the central problem
- propose one realistic action
- explain the mechanism
- acknowledge one limitation or risk
- include a way to test whether the proposal works
Self-check
□ My proposal directly addresses the defined problem.
□ I explained how the proposal would work.
□ I included a meaningful limitation.
□ Every sentence has a role.
□ I revised one sentence for effectiveness, not merely grammar.

解答・解説・自己修正
Reading answers
Q1｜解答例
It is designed to reduce blocked access caused by bookings that users no longer intend to use but have not cancelled.
Q2｜解答例
The center should consider the possibility that low demand, not only overbooking, is contributing to the empty rooms.
WF04｜提案・解決策
proposalだけでは不十分。
problem → proposal → mechanism → limitation/mitigation
がつながって初めてsolution writingになる。
WQ04 Transfer
E087で導入したEffectiveを別文脈Free answerへTransferする。接続詞の数ではなく、各文の役割と情報配置で評価する。
Model answer
The center should test a confirmation system rather than immediately imposing strict booking limits or large fees. The main problem is that unused reservations can block rooms for other groups. Requiring confirmation two days before use would release bookings that people no longer need while allowing genuine multi-date users to keep theirs. However, some users may forget to confirm, so the center should send one reminder. A one-month trial should measure how many released rooms are rebooked before the rule becomes permanent. This would also show whether reminders reduce accidental reservation waste.
Self-correction
proposal文だけを読んで「なぜ効くか」が推測に頼るなら、mechanismを明示する1文を足すか既存文を直す。
