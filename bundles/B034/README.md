# B034 — P3 Final Gate

## Purpose

B034 closes P3.

This bundle does not introduce a major new focus. It verifies that previously learned reading, discourse, source-integration, summary, translation, and writing skills can be reproduced under exam-like time pressure.

Primary gate axes:
- main claim / evidence strength
- reference and paragraph function
- concession / qualification
- dense-sentence decomposition
- sentence insertion
- multiple-source integration
- English summary
- Japanese synthesis
- text-linked / summary-linked writing
- time allocation and output switching

All materials are Core 60 minutes.
E204 is the formal P3 Final Gate.

Materials:
- E199: evidence strength and claim calibration
- E200: reference tracking and insertion in an abstract passage
- E201: dense sentence + translation + qualification
- E202: paired passages + summary-linked evaluation
- E203: mixed-source pre-final rehearsal
- E204: P3 Final Gate cumulative mock
