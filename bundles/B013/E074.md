E074｜図書館の夜間開館：本文と表を一緒に読んで判断する
P2 / LT01 / RQ13 複数資料統合 / SS03 / TF11
今日の狙い
英文本文と表を別々に処理せず、本文が示す評価基準と表の数値・属性を対応づける。表だけ、本文だけで答えられる設問に逃げない。
時間配分
Integration Guide 5分 / Reading 12分 / Data Table 7分 / Integration Questions 11分 / Short Output 7分 / Self-check 3分 ＝ 演習 45分 / Post-solve 6分（時間外）
Integration Guide
1. 本文から「何を比較すべきか」を取る
2. 表からその比較に必要なセルだけを拾う
3. 数字が大きい＝正解と決めない
4. 本文の条件と表のデータを1つの文に統合する
Reading
[1] A public library is considering whether to extend opening hours into the evening. A simple argument would compare the number of current visitors with the expected cost of staying open longer. That comparison is incomplete, however, because current visitor counts may underrepresent people who cannot use the library during existing hours.
[2] A pilot survey therefore asked not only how often different groups currently visit but also whether evening hours would make access easier and what barrier most often prevents a visit. The results should not be treated as precise forecasts of future attendance. Reported interest can be higher than actual behavior. Even so, the pattern can reveal which groups are poorly served by the current schedule.
[3] The decision should also consider cost per additional useful visit, not just total interest. If a group already visits frequently during current hours, extending the schedule may add convenience without creating much new access. By contrast, a group with low current use and a strong schedule-related barrier may gain more from the same change.
[4] The best interpretation therefore combines current use, reported benefit, and the type of barrier. No single column in the table is sufficient by itself.
[5] The survey also creates a fairness question. Extending hours for a group that already uses the library frequently may increase total visits more quickly, while extending hours for a group blocked by the current schedule may create more new access per person served. Those are different definitions of success. A pilot should therefore state whether it is trying mainly to increase total use, reduce schedule-related exclusion, or learn which groups change behavior when hours change. The table can support each question differently, so the purpose of the pilot must be clear before the numbers are interpreted.
[6] A short pilot can help separate those goals. If evening use rises mainly among people who already visited often, the change may be increasing convenience. If use rises among people who previously reported schedule barriers, the same increase may represent newly created access. The number of additional visits matters in both cases, but its meaning depends on who makes those visits and why the previous schedule limited them.

Reading answers
Q1｜B
本文は「low current use + strong schedule-related barrier + high reported benefit」を重視する。表ではGroup Bがその組合せを最も明確に示す。
Q2｜解答例
Group C already has the highest current visit rate, so high interest in evening hours may reflect added convenience rather than unmet access under the current schedule.
別解：Group C の main barrier は limited study space であり開館時間ではないため、開館時間を延ばしても主な障壁は解消されない（[4] の type of barrier）。
Q3｜解答例
Because what people say they would use may be higher than their actual future behavior.
Q4｜解答例
Group B should be investigated first because it currently visits infrequently but reports a strong benefit from evening hours. Its main barrier is the current schedule, which matches the access problem described in the passage.
Short Output｜例
current use / reported benefit / the type of barrier（順不同）


RQ13｜複数資料統合
RQ13は「本文を読んでから表の最大値を探す」問題ではない。
本文が evaluation rule を与え、表がそのruleを適用する材料を与える。両方が必要。
SS03
SS03は本文＋表・グラフ等の非連続資料。表の数字だけでなく、本文の条件・定義・限定と対応づける。
Self-correction
自分のQ1/Q4で、本文由来の基準と表由来のデータを色分けするつもりで分けて確認する。片方しかなければ統合になっていない。
到達目安
A：本文の評価軸を表へ適用し、複数セルを統合して判断できる。
B：表は読めるが、本文の条件と結び付けるのに時間がかかる。
C：最大値・最小値だけで答えを決める。
