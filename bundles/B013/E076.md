Reading
[1] Museums sometimes reduce the time that sensitive objects remain on display because light can gradually change some materials. The relevant idea is cumulative exposure: the total effect depends on both the intensity of light and the length of time an object receives it. A lower light level for a very long period can therefore matter, just as a higher level for a shorter period can.
[2] This does not mean that every object should be kept in darkness. Display has educational value, and different materials have different sensitivity. A practical plan can combine lower intensity, shorter display periods, rotation with similar objects, and rest periods in storage. The aim is to manage exposure while still allowing visitors to see the collection.
[3] Suppose a small exhibition has four objects. The table gives a simplified planning score. “Sensitivity” describes how easily the material may change under light; “weekly display hours” shows planned time in the gallery; and “light level” is an index used only for this exercise. The table is not a scientific standard. It is a fictional planning tool for applying the passage’s logic.
[4] A curator should not choose an object for rotation simply because one number is largest. A highly sensitive object with moderate hours may deserve attention, while a less sensitive object with long hours may be acceptable. The decision has to combine material sensitivity with both duration and intensity.
[5] Rotation decisions also have to consider what can substitute for an object while it rests. If two objects communicate a similar idea to visitors, rotating them may preserve educational value with little loss. If an object is unique to the exhibition’s central argument, the curator may prefer to reduce its light level before reducing its display time. The table does not contain this interpretive information, so it should not be treated as a complete decision system. It is one source used under the passage’s exposure rule.

Integrated answers
Q1｜B
Object BはSensitivityがHighで、display hours 32、light level 6。High sensitivityの中で時間・強度の組合せがより大きく、本文の複合基準に合う。
Q2｜解答例
The passage says exposure decisions must combine sensitivity, duration, and intensity. Object C has long display hours, but its lower sensitivity and light level also matter.
Q3｜解答例
Cumulative exposure is the total effect of light over time, depending on both how strong the light is and how long the object receives it.
Q4｜解答例
光による影響は素材の感受性だけでなく、照明の強さと展示時間の組合せで変わるため、時間が最長という一項目だけでは判断できない。
Japanese Output｜例
素材のsensitivity、展示のduration、照明のintensityを合わせて見て、光による累積的な影響が大きくなるものから優先してローテーションの対象にする。
