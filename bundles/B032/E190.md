E190｜古いモデルは「誤り」になったのか：旧説から新説への更新を読む

P3 / LT03 / D08 / RQ03 / RQ08 / RF04 / A13 / SS01 / TF03

今日の狙い
旧モデル→新しい観測→修正モデルという流れを読み、古い説明が完全に無価値になる場合と、限定的に残る場合を区別する。

時間配分
Silent Plan 1分 / Reading 13分 / Model Shift 6分 / Questions 7分 / Translation 6分 / Self-check 2分 ＝ 演習 35分 / Post-solve 6分（時間外）

Reading
[1] Scientific models are often described as if one model simply replaces another when new evidence appears. In practice, revision can be more complicated. A newer model may reject an older assumption while preserving part of the older model as a useful approximation.

[2] Consider a fictional model of animal movement. Early researchers assumed that individuals moved randomly within a fixed area. The model predicted the average number of encounters between animals reasonably well when food was distributed evenly.

[3] Later tracking data showed that movement changed when food became concentrated in patches. Animals repeatedly returned to a small number of locations, producing clusters that the random-movement model could not explain.

[4] Researchers therefore introduced a second model in which movement depended partly on remembered resource locations. This new model explained both repeated returns and differences between evenly distributed and patchy food conditions.

[5] Did the new model make the old one useless? Not entirely. Under conditions where resources were nearly uniform and memory had little effect on movement, the older random model still produced acceptable average predictions. Its weakness was not that it never worked, but that its assumptions were narrower than researchers had first believed.

Dense Sentence
What changed was therefore not merely the preferred equation but the claimed range of conditions under which the simpler model could be treated as an adequate representation of movement.

[6] Model revision, in this example, means changing both explanation and scope. The newer model accounts for a mechanism the older one omitted, while the older model survives as a limited approximation under specific conditions.

Q4｜RQ09

Q1｜解答例
Researchers first used a random-movement model. Tracking data then revealed repeated returns under patchy food conditions. They introduced a memory-based model that explained the new pattern while retaining the older model as an approximation under more uniform conditions.

Q2｜解答
It refers to the weakness of the older random-movement model.

Q3｜解答例
Scientific revision can change the mechanism and the scope of a model without making the older model completely useless.

Q4｜解答例
It can still be useful when resources are nearly uniform and memory has little effect, because under those conditions it gives acceptable average predictions.

Q5｜解答例
A model can be limited because its assumptions work only under certain conditions; that is different from a model that fails under every condition.

Translation｜和訳例
したがって変わったのは単に採用される式ではなく、より単純なモデルを動物の移動の十分な表現として扱えると主張できる条件の範囲そのものであった。

## 解説の考え方

### この問題で考えること
新しいモデルが出たとき、「old = wrong / new = true」という二択ではなく、**どの mechanism が追加され、旧モデルの適用範囲がどう狭まったか**を見る。

### 考え方
旧モデルは uniform resources では平均予測に役立ったが、patchy resources で repeated return を説明できなかった。tracking data がその失敗条件を示し、memory mechanism を含む新モデルが導入された。結果として旧モデルは消えるのでなく、**memory effect が小さい条件での approximation**として残る。

### 弱い考え方との比較
× 「新モデルが出たので旧モデルは誤り」  
○ 「旧モデルは一部条件では有用だが、想定していた scope が広すぎた。新証拠は mechanism と適用範囲を更新した」  
改善点は、モデル評価を **truth label ではなく adequacy under conditions** で考えること。

### 次の問題に持っていくもの
理論・モデルの更新では、**何が反証されたか / 何が残るか / どの条件なら近似として使えるか**を分ける。


Self-correction
old→new を「旧説全否定」にしない。mechanism と scope の両方が更新される。

到達目安
