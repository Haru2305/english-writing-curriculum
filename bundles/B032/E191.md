E191｜出土品の由来をどう判断するか：記録・ラベル・材料分析を統合する

P3 / LT03 / D09 / RQ09 / RQ13 / RF06 / SS05 / TF11

今日の狙い
複数資料の一致と不一致から、個別事例を一般化しすぎずに出土品の由来を日本語で統合する。

時間配分
Silent Plan 1分 / Field Note 8分 / Catalog 7分 / Analysis Table 9分 / Questions 11分 / Integration Plan 5分 / Japanese Summary 14分 / Self-check 2分 / Post-solve 4分 ＝ Core 60分

Field Note
A fictional excavation records four ceramic fragments found near the remains of a riverside storehouse. The field note states that Fragments 1–3 were recovered from the same soil layer. Fragment 4 was found nearby but in disturbed soil, so its original position is uncertain.

Catalog Note
A museum catalog created decades later labels all four fragments as “probably imported.” The label was based mainly on decoration that resembled ceramics from another region. The catalog did not have access to later material analysis.

Analysis Table
Fragment | Soil context | Decoration similarity | Clay composition | Current interpretation
1 | same layer | high | local | likely local imitation
2 | same layer | high | non-local | likely imported
3 | same layer | medium | local | likely local
4 | disturbed | high | non-local | origin plausible, context uncertain

[1] The new analysis complicates the old catalog label. Similar decoration does not map perfectly onto material origin. Fragment 1 resembles imported ware but uses local clay, suggesting that local producers may have copied an external style.

[2] Fragment 2 provides a different case: both decoration and clay composition support an imported origin. Fragment 3 is more clearly local. Fragment 4 may also be imported, but because its soil context is disturbed, it is harder to use as evidence about what was stored in the building during a particular period.

[3] The broader conclusion should therefore be narrower than “all decorated fragments were imported.” The site appears to contain both imported ceramics and local objects influenced by outside styles.

Questions
Q1｜RQ13
Which fragment most clearly contradicts the old catalog label?

Q2｜D09
How does Fragment 1 support a broader generalization about style and origin?

Q3｜RQ09
Why is Fragment 4 weaker evidence about the storehouse period than Fragment 2?

Q4｜RQ13
Which sources support the interpretation of Fragment 2?

Japanese Summary

「旧ラベル」「材料分析による修正」「Fragment 1と2の違い」「Fragment 4の文脈上の弱さ」「最終的な一般化」を含める。

Self-check

解答・解説・自己修正

Q1｜解答例
Fragment 1, because its decoration resembles imported ware but its clay composition is local, indicating a likely local imitation.

Q2｜解答例
It shows that an imported-looking style can be produced locally, supporting the broader conclusion that decoration alone does not determine geographic origin.

Q3｜解答例
Because Fragment 4 was found in disturbed soil, so even if the object itself was imported, its original relationship to the storehouse layer is uncertain.

Q4｜解答例
The catalog supports an imported interpretation from decoration, and the later material analysis supports it more directly through non-local clay composition; the field note also gives Fragment 2 a secure layer context.

Model Japanese summary
