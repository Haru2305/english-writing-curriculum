E212｜筑波Day8：大問3統合―整序3問＋約100語英作文を60分で完遂P4 / Tsukuba Day 8 / final 60-min Q3 integration drill / Core 60今日の狙い大問3Aの整序3問を「全文完成→3番目・5番目確認」で処理した直後に、3Bの約100語自由英作文へ切り替える。60分パーツ演習の最終日。時間配分Context reading 6分 / Word order 16分 / Position audit 6分 / Prompt analysis 5分 / Planning 5分 / Draft 13分 / Revision & count 6分 / Self-check 1分 / Post-solve 2分 ＝ Core 60分ContextUniversities send students a large amount of information: registration instructions, scholarship notices, safety updates, event announcements, and changes to campus services. Because many messages are long, some students read only the first few lines or postpone reading them.Automatic summarization may help by placing the required action, deadline, and main condition near the top. However, a summary is still a reduced representation of the original notice. A rare exception, special eligibility rule, or warning may disappear if the system treats it as less important.For this reason, a useful summary should not replace the original document. It should help students identify what they need to check next. Universities also need to know whether students actually understood the message rather than merely opened it.Part A｜Word Order1. Students often ignore important information when an email is too long, so a clear summary could help them notice deadlines and required actions. However, an automatic summary may omit a condition or exception. For example, a scholarship notice might mention an earlier deadline for international applicants. The university should therefore show the original notice directly below the summary and warn students to check it before making an important decision. This would improve convenience without treating the summary as fully reliable.自己修正Day8で固定する順序は「整序全文→位置確認→英作文の問いへ直答→理由→具体例→約100語」。ここから先はこの処理を長文セクションと同じセット内で切り替える。到達目安A：整序3問の位置正答＋英作文90〜110語で条件完遂B：整序または作文は成立するが切替で時間超過C：指定位置ミス、または英作文が未完
