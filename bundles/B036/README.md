# B036 — Tsukuba P4 Days 7–12

## Purpose

Transition from the final 60-minute part drills into semi-full Tsukuba sets. Days 7–8 close the isolated-part phase; Days 9–12 progressively connect long reading, strict Japanese explanation, Q3A word order, and Q3B free composition under 90–120 minute limits.

## Sequence

- E211 / Day 7: final 60-minute Q1-style reading speed drill — strict Japanese explanation / cloze / heading / order
- E212 / Day 8: final 60-minute Q3 integration — 3 word-order items + about-100-word free composition
- E213 / Day 9: Semi-full A / 90 min — Q1-style reading + Q3A + Q3B
- E214 / Day 10: Semi-full B / 100 min — Q2-style science reading + Q3A + Q3B
- E215 / Day 11: Semi-full C / 110 min — Q1-style reading + Q2-style reading
- E216 / Day 12: B036 Checkpoint / 120 min — Q1 + Q2 + Q3A + Q3B in one continuous set

Design: TPL-v4-P4-TSK.

Priority:
1. strict-character-limit Japanese explanation under fatigue
2. section switching without carrying the previous passage's logic forward
3. designated-position accuracy after full word-order reconstruction
4. about-100-word free composition completed after reading sections
5. fixed section stop-times before full-set training in later P4
