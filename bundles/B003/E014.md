Pre-solve Grammar
有限動詞は、直前の名詞ではなく主語のheadに一致します。


The number of passengers is falling.
主語head = number → is


A number of passengers are older residents.
意味上「多くのpassengers」→ are


Each route has fixed costs.
each + 単数 → has


The cost of maintaining several rural routes remains high.
主語head = cost → remains
routes に引っ張られて remain としない


Review
invest in + 投資対象
invest A in B = AをBへ投入

Reading
Public transport can become difficult to maintain when a region loses population. The number of passengers may fall, but the cost of maintaining vehicles, routes, and staff does not fall at the same speed. A number of small communities are therefore forced to reconsider how services are organized.


Reducing the number of routes may lower some costs, but it can also make access worse for people who cannot drive. Each route serves a different pattern of schools, hospitals, shops, and workplaces. The value of a service is therefore not measured only by how many passengers use it. A route with relatively few riders may still be essential if there is no realistic alternative. In addition, low ridership can partly reflect an inconvenient timetable rather than a lack of demand for transport itself. If buses run only a few times a day, some residents may stop using them even though they would use a more reliable service.


Some regions invest in smaller vehicles, flexible routes, or shared transport systems. These options can reduce empty trips, but coordination remains important. A network of several low-frequency services is useful only if connections allow passengers to complete their journeys. Flexible booking can also create new barriers if reservations require a smartphone or must be made far in advance. A cheaper system is not automatically more accessible, so planners need to consider both operating cost and the ease with which different groups can actually use the service.


The challenge is to maintain enough access without pretending that every old route can remain unchanged. The cost of preserving a service and the number of people who depend on it both matter. A sustainable system may therefore combine fewer fixed routes with more flexible forms of transport.

G17｜主語・動詞一致
1. is
headはnumberです。


2. need
A number of + 複数名詞は「多くの〜」で複数扱いです。


3. has
each + 単数名詞なので単数動詞です。


4. remains
headはcostです。servicesではありません。


5. is
accessが主語headです。

近くのpassengersに引っ張られています。


The cost of several routes remain ...

### この問題で考えること
Grammarでは、長い主語の中で**head nounを先に確定してから有限動詞を決める**ことが処理手順です。内容面では、ridershipという一つの数字とservice valueを同一視しません。

### 処理手順
1. 主語全体を囲う
2. of以下などの修飾を外してheadを探す
3. headの単複で有限動詞を決める
4. その後に文の意味を確認する

"The cost of maintaining several rural routes remains high." なら head は cost で、routesではありません。

### 内容面の弱い考え方との比較
× Fewer passengers → the route has little value.
○ Fewer passengers can make financing harder, while the route may remain essential for people without alternatives.

### 次の問題に持っていくもの
**grammarではnearest nounではなくhead、policyではvisible countではなくfunction**を見る、という二つの「中心を見抜く」処理を残します。
