Passage A｜Searchable Text
A fictional archive has scanned thousands of handwritten notebooks and produced searchable text with automatic character recognition. Searchability changes how researchers work. Instead of opening notebooks one by one, they can search for a person, place, or phrase across many volumes in seconds.

This convenience is substantial, but searchable text is not identical to the original page. Character-recognition software can misread unusual handwriting, damaged paper, abbreviations, or faded ink. A search for one spelling may therefore miss a relevant page even when the page has been scanned correctly.

For this reason, the archive describes the searchable layer as a navigation aid rather than a replacement for the image. That description does not reduce the value of search. It clarifies what kind of claim the digital text can safely support.

Passage B｜Normalized Transcript
A second project creates edited transcripts for selected notebooks. Editors expand common abbreviations, standardize some spelling, and mark uncertain words. This makes the text easier to read and compare, especially for users unfamiliar with older writing conventions.

Although normalization improves readability, it can hide features that matter to some research questions. A change in spelling may be irrelevant to someone tracing shipping routes but important to someone studying language use. The project therefore links every normalized transcript to the corresponding page image and records major editorial changes.

Table

Searchable OCR text | Fast search across volumes | recognition errors | Yes | finding candidate pages

解答・解説・自己修正

Q1｜解答例
The searchable text is useful for locating likely relevant pages, but it should not be treated as the final authoritative version of what the handwritten page says.

Q2｜解答
It refers to calling the searchable text a navigation aid rather than a replacement for the original page image.

Q3｜解答例
The passage concedes that normalization makes old writing easier to read and compare before arguing that editorial changes can hide features important to some research questions.

Q4｜解答例
OCR text is especially convenient for searching many volumes quickly but may contain recognition errors. Normalized transcripts are easier to read closely but can hide original spelling or abbreviation through editorial choices.

Q5｜解答例
Because both OCR and normalized transcripts transform the original. Researchers who need exact wording or visual features must verify them against the page image.

Model summary
The archive uses three digital layers for different purposes. Page images preserve the closest visual record but are slow to search. OCR text helps researchers locate candidate pages quickly, although recognition errors can hide relevant material. Normalized transcripts make older writing easier to read and compare, but editorial changes may remove variation that matters for some questions. Linking both text layers to page images allows convenience without treating transformed text as the final authority.

Model writing
A researcher should begin with OCR text to search many notebooks quickly and identify likely relevant pages. A normalized transcript can then help interpret difficult handwriting or abbreviations, but the researcher should check every quotation against the linked page image before using it. This workflow combines speed with fidelity: searchable text reduces the time needed to locate material, while the image preserves the original wording and visual evidence. The trade-off is extra verification time, but that cost is justified when quotation accuracy matters more than simply finding references. That verification step should remain mandatory.
