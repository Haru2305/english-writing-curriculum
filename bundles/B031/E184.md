E184｜博物館展示をどう読むか：カタログ・学芸員メモ・配置表を日本語で統合する

P3 / LT03 / RQ03 / RQ13 / D02 / RF06 / SS05 / TF11

今日の狙い
文章・メモ・配置表の役割を分け、展示順が「年代順」と「解釈の確実さ」を同時には表していないことを日本語で統合する。

時間配分
Silent Plan 1分 / Catalog 10分 / Curator Note 8分 / Table 8分 / Questions 10分 / Integration Plan 5分 / Japanese Summary 13分 / Self-check 2分 / Post-solve 3分 ＝ Core 60分

Catalog
A fictional museum presents an exhibition called “Making a Harbor.” The first room contains maps, tax records, tools, and household objects from several periods. The exhibition is not arranged strictly by date. Instead, each section asks a question: How was the shoreline used? Who paid for shared structures? How did new transport routes change work?

One display shows a wooden measuring tool beside a later map of warehouse plots. The objects were not used at the same time, but the museum places them together to compare two ways of organizing space.

Curator Note
Visitors sometimes assume that objects shown next to each other must come from the same period. That is not always the case. Adjacency can signal comparison rather than chronology. Labels therefore include dates, source type, and a short statement about why items are grouped.

The note also warns against another assumption. A detailed label does not necessarily mean that the museum is more certain about an object. Some poorly documented objects require longer labels precisely because the evidence is incomplete and several interpretations must be explained.

Display Table
Section | Main question | Earliest item | Latest item | Evidence note
A Shoreline | How was water access organized? | 1810 | 1875 | Several maps agree
B Work | How did tools and jobs change? | 1795 | 1890 | Some tools lack owner records

D Movement | How did routes reshape travel? | 1820 | 1925 | Maps clear; motives debated

解答・解説・自己修正

Q1｜解答
It refers to the assumption that objects displayed next to each other must come from the same period.

Q2｜解答例
The Catalog states this directly and gives the wooden tool and later warehouse map as an example; the table also supports it because each section spans wide date ranges.

Q3｜解答例
The catalog says sections are organized by questions rather than strict chronology. Placing a tool beside a later map shows how objects from different dates can be grouped to compare ways of organizing space.

Q4｜解答例
Because an uncertain object may require a longer explanation to describe missing evidence and competing interpretations.

Model Japanese summary
この展示は年代順ではなく、港の利用や仕事の変化などの問いごとに資料を配置するため、隣接する物が同時代とは限らない。年代表示は比較対象の時期を確認する手掛かりとなる。また長い解説は確信の強さを意味せず、証拠不足や複数解釈を示す場合もある。表からも、地図・税記録・所有記録など証拠の強さが区画ごとに異なると分かる。

## 解説の考え方

### この問題で考えること
展示の見た目をそのまま証拠の意味にしない。**配置・年代表示・説明量・証拠の確実性**はそれぞれ別の情報である。

### 考え方
Catalog は「問いごとに配置する」という organizing principle、Curator Note は adjacency と label length の誤読を防ぐ条件、Table は各 section の date range と evidence strength を示す。したがって、隣り合う資料から chronology を推定したり、長い label から certainty を推定したりしてはいけない。

### 弱い考え方との比較
× 「隣にあるから同時代」「説明が長いから確実」  
○ 「隣接は comparison のためかもしれず、長文は不確実性を説明するためかもしれない」  
改善点は、**presentation feature と evidential meaning を直結させない**こと。

### 次の問題に持っていくもの
複数資料では、まず各資料の仕事を分ける。**principle / warning / evidence** のように役割を整理すると、表面上の配置や説明量に引っ張られにくい。


Self-correction
配置・説明量・確実性を同一視しない。各資料が何を示すために置かれているかを読む。
