E207｜筑波Day3：大問3A―文脈内整序を構文ブロックで処理する

P4 / Tsukuba Day 3 / Q3A-style word order / Core 60

今日の狙い
整序問題を意味の勘ではなく、文型・修飾・時制・完了・受動の構文ブロックから復元する。

時間配分
Passage 12分 / Ordering 28分 / Grammar review 10分 / Recheck 5分 / Self-check 2分 / Post-solve 3分 ＝ Core 60分

Passage

A research team studying urban birds asked volunteers to record species seen during morning walks. At first, the project accepted every report equally. Researchers later realized that this created a problem: some volunteers walked for ten minutes, while others spent more than an hour outdoors.

To make reports more comparable, the project began asking volunteers to record observation time and distance traveled. The change did not make every report identical, but it allowed researchers to estimate how much effort had produced each list.

The team also discovered that unusual birds were more likely to be reported than common ones. A volunteer who noticed a rare species might submit a report immediately, even if no complete list had been recorded. As a result, the database could not be interpreted simply as a count of how often each species occurred.

Researchers therefore separated complete observation lists from isolated rare-species reports. The former were used to compare relative frequency after effort was considered, while the latter were treated mainly as signals for follow-up observation.

Ordering

1. The team found that some apparent differences between sites
   ( amount / by / could / explained / of / observation / the / be / effort ).
   Complete the sentence.

2. Rare reports
   ( been / more / may / noticed / likely / have / to / than / common species )
   because unusual observations attract attention.

3. The revised protocol
   ( did / every / not / report / make / directly / comparable ),
   but it reduced one important source of uncertainty.

4. Researchers wanted to know
   ( birds / differed / whether / sites / because / actually / or / effort / differed )
   across locations.

5. Some records
   ( found / to / have / were / been / submitted )
   without a complete observation list.

6. The project changed its database structure
   ( so / different / that / could / record types / used / be / for / different questions ).

Grammar Check

A. Why is “have been submitted” appropriate in Question 5?
B. In Question 1, identify the passive construction.
C. In Question 4, what is the grammatical role of “whether”?
D. In Question 6, why is “could be used” passive?

Context Check
In 40–60 English words, explain why the project should not combine all record types into one simple count.

Self-check
□ まず主語・動詞を確定した
□ be + p.p. / have + p.p. / to have + p.p. を区別した
□ 整序後に本文文脈へ戻して意味を確認した

---

解答・解説・自己修正

1
could be explained by the amount of observation effort

2
may have been more likely to be noticed than common species

3
did not make every report directly comparable

4
whether birds actually differed because sites differed or effort differed

5
were found to have been submitted

6
so that different record types could be used for different questions

Grammar Check
A. 提出が「発見された」時点より前に起きているため、完了形の受動不定詞 to have been submitted が必要。
B. could be explained
C. know の目的語となる間接疑問節を導く接続詞。
D. record types は「使う側」ではなく「使われる対象」だから。

Context Check｜解答例
The records were produced under different observation conditions and for different reporting purposes. Complete lists include broader information about effort, while isolated rare-species reports are selectively submitted. Combining them into one count would mix unlike forms of evidence.

自己修正
筑波整序は「意味が通る」では足りない。構文骨格→修飾→時制→文脈の順。

到達目安
A：6問中5〜6問を構文根拠つきで正解
B：4問正解だが完了・受動で揺れる
C：3問以下、または語感頼み
