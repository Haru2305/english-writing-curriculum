E134｜記憶と学習：接続語ではなく論理で空所を埋める

P3 / LT01 / RF07 Guided / D01 Review / RQ05 / TF05



今日の狙い

接続語そのものを暗記して当てるのではなく、前後文の関係を「追加・対比・因果・具体化」に分類して空所を埋める。



時間配分

Logic Blank Guide 5分 / Reading 18分 / Questions 10分 / Blank Tasks 14分 / Reconstruction 5分 / Self-check 3分 / Post-solve 5分 ＝ Core 60分



Logic Blank Guide

1. 空所の前後を要約する

2. 関係を addition / contrast / cause-effect / example に分類する

3. 接続語の意味がその関係に合うか確認する

4. 文法的に入るだけの選択肢を除外する



Reading

[1] Students often judge learning by how familiar material feels while they are studying. Rereading a page can create a strong sense that the content is known because the sentences become easier to process. [Blank 1], ease during study does not always predict whether the information can be recalled later.



[2] Retrieval practice works differently. Instead of presenting the answer again, it asks the learner to produce information from memory. This can feel slower and less comfortable than rereading. [Blank 2], the effort required to retrieve an answer can strengthen later access to that information.



[3] The benefit is not unlimited. If a question is so difficult that the learner repeatedly fails without useful feedback, practice may become inefficient. [Blank 3], effective retrieval tasks are usually challenging enough to require effort but not so difficult that success becomes rare.



[4] Spacing also matters. Ten retrieval attempts completed in a few minutes may create less durable learning than the same number distributed across several days. The delay introduces some forgetting. [Blank 4], that partial forgetting makes each later retrieval less automatic and therefore more demanding.



[5] None of this means that rereading is useless. It can help a learner first understand a complex explanation or check missing details after an attempt. The problem arises when familiarity is treated as proof of durable memory. A useful study plan combines understanding with opportunities to retrieve information after some delay.

解答・解説・自己修正



Q1｜b. However

The first sentence describes familiarity as a positive feeling, while the next sentence limits what that feeling predicts. The relation is contrast.



Q2｜f. At the same time

The passage contrasts discomfort with a simultaneous benefit. “Therefore” would incorrectly make discomfort itself a sufficient cause.


別解：b. However も可。「不快に感じる／それでも想起を強める」という対比として読めるためです。f は「不快さと利益が同時に成り立つ」関係をより直接に示します。



Q3｜e. Therefore

Repeated failure makes practice inefficient; the next sentence gives the resulting design principle.


補足：a. As a result は「出来事の結果」を表します。ここは失敗が続くことから課題設計の原則を導く「論理的な結論」なので e が最適です。



Q4｜a. As a result

The delay causes partial forgetting, and that forgetting makes later retrieval more demanding.


別解：e. Therefore も可。a と e はどちらも結果・帰結を表します。差は「時間の経過に沿った出来事の結果」（as a result）か「論理的な結論」（therefore）かで、Q4 は前者、Q3 は後者の方が自然です。



Q5｜解答例

Spacing allows some forgetting to occur, so later retrieval requires more effort and can strengthen durable access rather than becoming automatic repetition.



RF07｜接続語空所

接続語問題は語彙問題に見えて、実際には論理関係の識別問題であることが多い。

前後を短く言い換え、

contrast / result / addition / example

のどれかを先に決める。



Model reconstruction

Feeling familiar with material can overestimate learning, whereas effortful retrieval better tests access; when retrieval is appropriately difficult and repeated after delays, the resulting effort can support more durable memory.



Self-correction

選択肢を隠して前後関係を日本語または英語で一言にする。その後で初めて接続語を見る。



到達目安

B：正解するが、説明が「自然だから」に留まる。

C：接続語の訳だけで選ぶ。
