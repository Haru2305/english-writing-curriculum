# 表現集(試作)

E085〜E096 の模範答案から作成。機能ごとに、型・例文・使い方・注意点を並べています。

## 答える・主張する

### The X should first test A because ...

> The school should first test a quiet zone because the strongest criteria are reducing a documented access barrier and producing clear evidence within a short period.

- 使い方: 最初の一文で「何を先にやるか」と理由の核を同時に出す
- 注意: first test と書くと『まず試す』になり、断定的な『導入すべき』より安全
- 出典: E094

### The X should prioritize A because it directly addresses ...

> The school should prioritize Option B because it directly addresses a documented scheduling barrier and can be tested within one term without requiring students to own special equipment.

- 使い方: 複数案から一つを選ぶ答え方。理由は判断基準に結びつける
- 注意: directly addresses の後ろは本文・表にある具体的な barrier にする
- 出典: E093

### A X should consider -ing ...

> A city should consider extending the hours of some public parks especially where many residents cannot use them during the day.

- 使い方: 断定を避けた提案の書き出し。consider で『検討すべき』にとどめる
- 注意: consider だけでは弱いので、直後に理由か条件を置く
- 出典: E087

### The X should test A rather than (immediately) B

> The center should test a confirmation system rather than immediately imposing strict booking limits or large fees.

- 使い方: 本命案と退ける案を一文で対比する
- 注意: 退ける案は『完全に否定』ではなく immediately の対象にして柔らかくする
- 出典: E092

## 主張の強さを調整する

### A suggests that ... but it does not show that ...

> The trial suggests that students value the homework-help session before major exams but it does not show that demand will remain high during ordinary weeks.

- 使い方: 『分かったこと』と『言えないこと』を一文で分ける
- 注意: show と suggest の強さの差に注意。suggest=示唆、show=はっきり示す
- 出典: E086

### The study shows that ... but this result does not prove that ...

> The study shows that the method can save time under the tested conditions but this result does not prove that organizations will adopt it quickly.

- 使い方: 結果の範囲(tested conditions)と、そこから先の主張を分ける
- 注意: prove は強い語。否定形で使うと言い過ぎを避けられる
- 出典: E085

### Adoption may become more likely if ...

> Adoption may become more likely if the method remains useful in real settings and if costs regulation training and compatibility do not create major barriers.

- 使い方: 可能性を条件付きで述べる(may + more likely + if)
- 注意: will にすると断定になる。条件 if を必ず添える
- 出典: E085

### ... would remain uncertain and would require evidence from ...

> broader industry effects would remain uncertain and would require evidence from more organizations and settings.

- 使い方: 分からないことを分からないと書き、必要な根拠まで示す
- 注意: uncertain と書くだけで終わらず『何が必要か』まで書くと答案が閉じる
- 出典: E085

### A may not represent B

> one month may not represent every season so the schedule should remain temporary until more evidence is available.

- 使い方: データの代表性の限界を述べる
- 注意: cannot ではなく may not にして過度な否定を避ける
- 出典: E089

## 理由・仕組みを説明する

### A directly addresses a documented ... barrier

> The school should prioritize Option B because it directly addresses a documented scheduling barrier

- 使い方: 『資料で確認できる問題に直接対応する』という選択理由の型
- 注意: documented は本文・表に根拠がある場合だけ使う
- 出典: E093

### ... because these measures answer different questions

> Public-service evaluation should distinguish among use user experience and reach because these measures answer different questions and may produce different results.

- 使い方: 区別する理由を『問いが違うから』で説明する
- 注意: may produce で『結果が違い得る』と控えめに書く
- 出典: E090

### Doing A would release ... while allowing ...

> Requiring confirmation two days before use would release bookings that people no longer need while allowing genuine multi-date users to keep theirs.

- 使い方: 対策の仕組み(メカニズム)を一文で説明する
- 注意: while で『副作用が小さい理由』を同時に示せる
- 出典: E092

## 具体化する(計画・根拠)

### The X could begin with ... and monitor A B and C

> The city could begin with two later evenings each week and monitor use complaints and costs.

- 使い方: 試行で何を観察するかを列挙して計画を具体化する
- 注意: 観察項目は3つ以内。目的に関係するものだけにする
- 出典: E087

### run the trial for N months and record ...

> The city should run the trial for three months and record attendance completed registrations and whether participants had previously been unable to use daytime support.

- 使い方: 期間と記録項目をセットで示す
- 注意: 期間と指標がないと『検証』にならない
- 出典: E095

### compare A with B to test whether ...

> The city should therefore run the Sunday opening for two months and compare new-user numbers repeat use and actual attendance with the survey prediction.

- 使い方: 予測と結果の比較で仮説を検証する計画を書く
- 注意: compare A with B。A to B ではなく with が基本
- 出典: E096

## 限定・譲歩する

### However, ... may ..., so the X should ...

> However some users may forget to confirm so the center should send one reminder.

- 使い方: 懸念を出し、その対処をすぐ続ける(限定→行動)
- 注意: 懸念だけで終わると答案が弱くなる。必ず so で対処に繋ぐ
- 出典: E092

### The main limitation is that ... so ...

> The main limitation is that group-work space would become smaller so the school should monitor congestion as well as quiet-zone use during a four-week pilot before making the change permanent.

- 使い方: 案の最大の弱点を一つだけ挙げ、監視する指標に繋ぐ
- 注意: limitation を複数並べず一つに絞る
- 出典: E094

### The main uncertainty is that ... may not become ...

> The main uncertainty is that survey interest may not become actual attendance.

- 使い方: 予測と実際の行動のずれを限界として示す
- 注意: uncertainty は『分からない点』。『問題点』とは区別する
- 出典: E096

### The current X is limited so ...

> The current survey is limited so a short follow-up test would provide stronger evidence before the library commits additional staff and operating costs.

- 使い方: 現在の根拠の弱さを認め、追加の根拠を提案する
- 注意: limited の理由(何が足りないか)を前の文で示しておく
- 出典: E090

### A could still help ... so it should not be abandoned

> A printed guide could still help people understand the different alert methods so it should not be abandoned.

- 使い方: 選ばなかった案にも価値を認める(譲歩)
- 注意: 譲歩だけで終わらせず、次の文で主張に戻る
- 出典: E095

### the policy should not be identical in every ... because ...

> However the policy should not be identical in every location because noise and staffing needs differ.

- 使い方: 一律ルールを避ける理由(条件の違い)を述べる
- 注意: because の後は具体的な違いの種類を2つ程度挙げる
- 出典: E087

## 比較・優先順位をつける

### Option A may ..., but it mainly ...

> Option A may attract more users but it mainly adds convenience to a service that many students can already access.

- 使い方: 退ける案の長所を認めつつ、本質的な弱点を述べる
- 注意: may で長所を認め、mainly で弱点の中心を絞る
- 出典: E093

### A is slightly more expensive, yet ... justifies the extra cost

> Option B is slightly more expensive than the cheapest choice yet the stronger connection to the school's access goal justifies the extra cost.

- 使い方: 費用面の不利を認めて、目的との整合で正当化する
- 注意: cost の不利を隠さずに書くと信頼性が上がる
- 出典: E093

### Adding A might serve ... but it would not help ...

> Adding more group tables might serve many students but it would not help those who currently leave because they cannot study quietly.

- 使い方: 別案が助ける人と助けない人を分けて比べる
- 注意: would not help の対象(those who ...)を具体的に書く
- 出典: E094

### more consistent with A than B

> which is more consistent with unmet schedule access than Option A's already-busy central room.

- 使い方: データがどちらの説明により合うかを比べる
- 注意: consistent with は『矛盾しない』。因果の証明にはならない
- 出典: E096

## 結論・意義で締める

### This would show whether ...

> This would show whether predictable basketball access reduces conflict without removing too much flexibility.

- 使い方: 試行で何が分かるかを結論文にする
- 注意: show whether + 疑問の内容。『分かる』ことを断定しない
- 出典: E089

### That evidence would show whether ... is a significant barrier

> That evidence would show whether access hours are a significant barrier.

- 使い方: 収集する根拠が判断にどう使えるかを書く
- 注意: would を使い、まだ結果が出ていないことを示す
- 出典: E095

### before the X commits ... / before the rule becomes permanent

> This limited follow-up would show whether the service has regular value before the school commits staff time to a permanent weekly program.

- 使い方: 恒久化の前に検証する理由を書いて結論を閉じる
- 注意: before の後に『何を決める前か』を明示する
- 出典: E086

### This would make the ... more evidence-based

> This would make the final funding choice more evidence-based.

- 使い方: 検証の意義を一文で締める
- 注意: 締めの一文は短くし、新しい論点を足さない
- 出典: E096

### This approach would preserve ... while keeping ... easy to reverse

> This approach would preserve access while keeping the trial easy to reverse.

- 使い方: 提案の利点(守るもの)とリスク管理(元に戻せる)で締める
- 注意: easy to reverse は小規模試行を勧める答案で使いやすい
- 出典: E087
