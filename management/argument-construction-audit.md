## Representative lesson audit

### P1 — embedded bridge

**E004**
- transfers causal language to a new topic
- asks the learner to explain why individual effort alone is insufficient
- produces a short answer with claim + causal support
- argument construction is present but subordinate to language retrieval

**E015**
- requires comparison between normal conditions and disruption
- makes the trade-off concept visible
- paragraph-function labels remain light

Finding:
- appropriate for P1
- do not add a six-step template

### P2 — explicit construction appears

**E087**
- explicitly teaches `claim → reason → qualification → action`
- requires a three-line plan
- labels sentence roles C/R/L/A
- integrates planning and revision

**E092**
- explicitly teaches:
  `problem → proposal → mechanism → limitation/mitigation`
- warns that a proposal without mechanism is not solution writing

**E093**
- explicitly teaches:
  `criteria → evaluation → choice`
- requires criteria to be fixed before selecting the preferred option

Finding:
- P2 is the natural place to name the common argument-construction framework once

### P3 — mechanism and qualification deepen

**E117**
- teaches a multi-step causal chain
- explicitly warns against skipping the mechanism
- uses conditions and side effects

**E119**
- teaches:
  `concede usefulness → reject overclaim → retain qualified claim`
- integrates multiple sources into a conditional judgment

Finding:
- P3 already supplies the content needed for ARG03 Mechanism and ARG05 Qualification

### P4 — compressed exam execution

**E208**
- explicitly requires:
  `position → reason → concrete example`
- the model answer uses one central reason, mechanism, example, and short qualification
- Post-solve explicitly says to answer the question directly, then give a reason and example

Finding:
- P4 should use a compressed internal routine, not more visible scaffolding

Recommended internal cue:

> **答えは？ → なぜ？ → どうして？ → 具体的には？ → 例外は？ → だから？**

## Main conclusion

The curriculum does **not** lack argument construction.

It already contains:
- reason selection
- mechanisms
- examples
- criteria
- trade-offs
- concession
- qualification
- conditional decisions
- planning and revision

The missing layer was curricular unification.

Different lessons teach local structures:
- claim / reason / qualification / action
- problem / proposal / mechanism / limitation
- criteria / evaluation / choice
- cause / effect chains
- concession / qualified claim
- position / reason / example

These are now unified by:
- `curriculum/argument-construction.md`
- `management/writing-type-argument-map.csv`

## Six functions

- ARG01 Answer / Position
- ARG02 Reason
- ARG03 Mechanism
- ARG04 Support
- ARG05 Qualification
- ARG06 Return / Decision

These are functions, not a six-sentence template.
